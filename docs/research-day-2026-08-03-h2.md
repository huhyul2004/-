## H2 가설
**세대시간(generational length)이 길수록 IUCN 위험 등급이 높을 것이다.**
- 근거: MTE(세대시간∝W^0.25), r-K 선택(K-전략자=긴 세대=회복 느림=취약).
- X=세대시간(년, log10), Y=RLI(LC=0…CR=4, EW/EX=5).
- 소스: IUCN API `supplementary_info.generational_length` 재조회(DB에 없어 신규 확보, 커버리지 55%).

## 체중과의 차이 (핵심)
- **체중(H1)**: 분류군 내로 들어가면 상관 소멸 → **심슨의 역설**(겉보기 상관).
- **세대시간(H2)**: 전체(+0.51)와 **포유류 내부(+0.38)가 같은 방향으로 견고** →
  분류군 내에서 **살아남은 첫 변수**. 착시로만 설명되지 않음.

## 정직성 한계 — 부분 순환 위험
세대시간은 순수 독립변수가 아니다. IUCN 기준 A/C/E가 개체수 감소를 **"3세대" 시간창**으로 측정.
→ 세대시간↑ → 평가 창↑ → 감소 더 포착 → 등급↑ 가능. 이는 (a)생물학적 취약성과
(b)방법론적 결합을 데이터로 분리 불가.

| 순환 유형 | 예 | 성격 |
|---|---|---|
| 완전 순환 | 개체수·기준코드 | 등급 직접 결정(동어반복) |
| **부분 순환** | **세대시간** | 등급 임계값 아니나 시간창 설정(간접) |
| 순수 외생 | 체중·평가연도 | 등급 산정에 안 쓰임 |

→ **+0.51을 "세대시간이 멸종위험을 인과적으로 높인다"로 해석하면 안 됨.** 체중은 이 문제가 없었다.

## 자소서 활용 방향
- **부분 순환 개념**으로 통계+방법론 이해 어필 (완전/부분/외생 3단 구분).
- **정직한 한계 명시**: 유리한 양의 결과에서도 순환 위험을 먼저 밝힘 = 연구 윤리.
- 체중(기각) → 세대시간(부분지지)으로 이어지는 **가설 반복 검증**의 탐구력.

## 3~4일 연구 총정리
- **H1 (체중)**: 기각 + **심슨의 역설** 발견 (분류군 내 무상관).
- **H2 (세대시간)**: **부분 지지** + **순환 위험** 인식 (포유류 내부 상관 생존, 단 방법론적 결합).
- **공통 통찰**: 통계 결과의 해석에는 **방법론(변수가 등급 산정에 얼마나 내재하는가) 이해가 필수.**
  상관계수의 크기보다 "그 변수가 결과를 만드는 데 얼마나 쓰였나"가 결론을 좌우한다.
