### 왜 107종뿐이었나

| 사실 | 수치 |
|---|---:|
| 전체 종 | 41,282 |
| 큐레이티드 종 | 4,230 |
| `mass_g` 보유 | 3,203 (7.76%) |
| **`mass_g` 보유 종의 분류군** | **포유류 3,203 (100%)** |
| `mature_individuals > 0` | **13** |
| `iucn_population_size > 0` | 308 |
| 둘 중 하나라도 > 0 | **311** |

**두 가지가 동시에 걸린다.**

1. **체중이 포유류에만 있다.** `mass_g` 는 PHYLACINE(포유류 전용 데이터셋)에서 왔고,
   3,203종 전부가 포유류다. 조류·파충류·양서류·어류·무척추·식물은 체중이 0종이었다.
2. **개체수가 311종에만 있다.** 41,282종 중 0.75%다.

두 조건의 교집합이 107종이다.

**IUCN 은 체중을 주지 않는다.** `species` 테이블의 IUCN 동기화 컬럼 17개를 전수 확인했다:

```
iucn_sis_id, iucn_category, iucn_criteria, iucn_assessment_id, iucn_assessment_year,
iucn_population_trend, iucn_possibly_extinct, iucn_url, iucn_synced_at,
iucn_population_size, iucn_kingdom, iucn_phylum, iucn_class, iucn_order, iucn_family,
iucn_generation_length, iucn_generation_length_raw
```

체중·질량 관련 컬럼은 **없다.** IUCN Red List API 가 체중을 제공하지 않아 외부 데이터셋이 필요했다.

### 204종으로 늘리기 위해 추가한 데이터셋

CSV 의 `mass_source` 실측값:

| 소스 | 종 수 | 분류군 | 받은 항목 |
|---|---:|---|---|
| PHYLACINE (원본 `mass_g`) | **107** | 포유류 | 성체 체중 |
| PHYLACINE (백필 `mass_g_external`) | **41** | 포유류 | 성체 체중 |
| AVONET (`mass_g_external`) | **56** | 조류 | 성체 체중 |
| **합계** | **204** | 포유류 148 · 조류 56 | |

DB `mass_g_external_source` 실측값으로도 확인된다:
`PHYLACINE(binomial)` 34 + `PHYLACINE(species→subspecies)` 7 + `AVONET1_BirdLife` 56 = **97**.
107 + 97 = 204.

**두 데이터셋 모두 체중만 받았다.** `generation_length` 는 별도로 IUCN API 에서 받았고
(`iucn_generation_length`), PHYLACINE·AVONET 에서 온 것이 아니다.

**파충류·양서류·어류·무척추 33종은 전용 체중 소스를 못 구해 제외됐다**

## 표 5: 두 결과가 반대인 이유

### 결론 — 원인은 **1번(표본 편향)과 2번(변수 차이) 두 개**이고, 3번(심슨의 역설)은 아니다

#### 근거 ① 두 결과는 다른 표본이다

| 표본 | 종 수 |
|---|---:|
| 204종 표본 | 204 |
| 4-B/4-C 의 모집단 (체중 보유 전체) | 3,300 |
| 교집합 | **204** |
| **4-B 에만 있고 204 에 없는 종** | **3,096** |

204 는 3,300 의 부분집합이고, **3,096종(94%)이 등급별 중앙값 계산에만 들어간다.**

#### 근거 ② 그 3,096종의 정체 — 개체수가 없는 소형 포유류

같은 LC 등급인데 두 표본의 체중이 **711배** 다르다.

| LC 표본 | n | 중앙값 |
|---|---:|---:|
| 204종 표본의 LC | 54 | **34.842 kg** |
| DB 전체의 LC | 2,647 | **0.049 kg** |

이유는 개체수 보유 여부다.

| LC 포유류 | n | 체중 중앙값 |
|---|---:|---:|
| 개체수 있음 | 53 | **32.183 kg** |
| 개체수 없음 | 2,594 | **0.047 kg** |

**685배 차이다.** 즉 "실측 개체수가 있는 종" 이라는 표본 조건이 **대형 포유류만 골라낸다.**
쥐·박쥐 같은 소형 LC 포유류는 개체수 조사가 안 되어 있어 204 표본에서 전부 빠졌고,
등급별 중앙값 계산에는 그대로 들어갔다.

#### 근거 ③ 변수 차이 — 로그를 씌우면 부호가 뒤집힌다

같은 204종 표본, 같은 Y(RLI 가중치 LC=0…CR=4)인데:

| X 변수 | Pearson r |
|---|---:|
| **log₁₀(체중)** | **−0.2417** |
| **원시 체중 (g)** | **+0.0239** |

원시 체중은 100톤(대왕고래)부터 3.7 g 까지 8자릿수에 걸쳐 있어 소수의 초대형 종이
상관을 지배한다. 로그를 씌우면 그 지배가 사라지고 소형 위협 조류가 드러나 음수가 된다.
**"음의 상관"은 로그 변환을 전제로 한 결과다.**

#### 근거 ④ 심슨의 역설은 아니다 — 분류군 안에서 부호가 뒤집히지 않는다

| 표본 | n | r (log 체중 vs 등급) | 등급 분포 | 체중 중앙값 |
|---|---:|---:|---|---:|
| 전체 | 204 | **−0.2417** | LC 54·NT 45·VU 22·EN 28·CR 55 | — |
| 포유류만 | 148 | **−0.0512** | LC 54·NT 45·VU 7·EN 8·CR 34 | 14.886 kg |
| 조류만 | 56 | **−0.1129** | **VU 15·EN 20·CR 21** (LC·NT 0) | 0.389 kg |

심슨의 역설은 "집단을 나누면 부호가 뒤집히는" 현상인데, 여기서는 **나눠도 셋 다 음수**다.
다만 −0.24 → −0.05 / −0.11 로 **크게 약해진다.**

실제로 일어난 일은 **집계 편향(aggregation bias)** 이다.
표본의 조류 56종은 **전부 위협등급(VU·EN·CR)이고 LC·NT 가 한 종도 없으며** 중앙값 0.389 kg,
포유류 148종은 **LC·NT 가 99종**이고 중앙값 14.886 kg 이다.
"작은 조류 = 위험 / 큰 포유류 = 안전" 이라는 **집단 구성 자체가** 음의 상관을 만들었고,
집단 안에서 체중이 등급을 설명하는 힘은 R² 로 0.26%(포유류)·1.27%(조류)에 불과하다.

**면접에서 "심슨의 역설"이라고 말하면 부정확하다.** 정확한 표현은
"분류군 구성에서 온 집계 편향" 또는 "교란변수(분류군)에 의한 겉보기 상관"이다.

## 부록: 그대로 쓸 수 있는 답변 문장

> "체중 가설을 204종으로 검정했습니다. log₁₀(체중)과 IUCN 등급 가중치의 Pearson r 은
> **−0.2417**(p = 4.97 × 10⁻⁴)로 유의했지만 **방향이 가설과 반대**였고 R² 는 5.8% 였습니다.
> 예를 들어 6.4 g 인 주황배개미새(*Terenura sicki*)는 CR 에 저희 점수 78.6점(T3)인데,
> 750 kg 인 북방코끼리물범(*Mirounga angustirostris*)은 LC 에 3.6점(T0)입니다.
> 체중이 117,000배 차이인데 점수는 정반대입니다.
>
> 그런데 DB 전체 3,300종으로 등급별 체중 중앙값을 내면 LC 0.048 kg → EX 10.0 kg 으로
> **정반대 방향**이 나옵니다. 원인을 두 개 찾았습니다.
> 첫째, 두 계산의 표본이 다릅니다 — 204종은 3,300종의 6%이고, 나머지 3,096종은
