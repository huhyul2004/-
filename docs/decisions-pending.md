## 2. Damuth K

### 현상

코드 K = `r < 0 ? max(N0×1.5, N0+100) : max(N0×1.2, N0+50)` — 체중·서식면적 입력 없음.
명세서(PKA-1551 C-1, 발명신고서 §8)는 Damuth 로 자바코뿔소 K ≈ 148, 코드는 126.
`lib/allometry.ts` 의 `damuthK()` 는 `evaluateTippingPoint` 가 호출하지 않는다 (호출처는 테스트뿐).
K 는 PVA 점수와 골든타임(h3) 날짜 산출 두 곳에 들어간다.

### 선행조건 3단계 — 각 단계 없이 진행하면

| 단계 | 현재 상태 | 이 단계 없이 도입하면 |
|---|---|---|
| ① 서식면적 데이터 | `habitat_area_km2` **컬럼 자체가 없음**, 보유 **0종** | `damuthK` 가 전 종에 `null` → **변동 0종**. 도입해도 아무 일도 안 일어난다 |
| ② kg/g 단위 (항목 6) | 상수 91.2 는 kg 기준, 함수는 g 을 받음 | K 가 **1/177.8 로 축소**. 자바코뿔소 K = **0.82** (N0 = 76 보다 작음) |
| ③ floor 재검토 (항목 1) | 미결정 | floor 에 묶인 종은 K 를 바꿔도 **점수 불변**. 자바코뿔소는 K 를 0.82~400 으로 500배 바꿔도 78.0 고정 (가중합 최대 72.16 < floor 78) |

## 6. damuthConstant — kg/g 단위 + 17개 분류군 fallback

### 현상 — 단위

`docs/phase2-allometry-constants.md` 는 "W = grams" 라 적고 포유류 d = 91.2 를 싣는다.
91.2 는 **kg 기준 상수**다.

| 계산 | 결과 |
|---|---:|
| 명세서 `91.2 × 2000^(−0.75) × 480` (kg) | 146.4 |
| 코드 `damuthK(2_000_000, "포유류", 480)` (g) | **0.82** |
| Damuth 1981 원식 `10^4.23 × 2e6^(−0.75) × 480` (g) | 153.3 |

`1000^0.75 = 177.8`, `91.2 × 177.8 = 16,218` ↔ 원논문 절편 `10^4.23 = 16,982`.
`__tests__/allometry.test.ts:37` 이 이 짝을 기대값으로 고정하고 있다.

### 현상 — fallback

전용 상수는 4개 (포유류 91.2 / 조류 55.0 / 파충류 12.0 / 양서류 200).
v5 `LIFE_HISTORY` 21개 분류군 중 **17개**가 포유류 91.2 로 fallback 한다 —
어류 3계열·곤충·거미류·갑각류·복족류·이매패류·산호류·식물 4계열·양치식물 2계열·이끼류·지의류.

### 근거 문서

- `docs/damuth-k-simulation.md` §2·§5
- `docs/phase2-allometry-constants.md` §3
