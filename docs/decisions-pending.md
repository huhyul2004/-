## 1. 개체수 floor

### 현상

`lib/tipping-point.ts` 605~618행. 개체수 N0 만 보고 종합 점수에 하한을 건다.
`Math.max` 라 점수를 올리기만 한다.

| 조건 | floor |
|---|---:|
| N0 < 50 | 90 |
| 50 ≤ N0 < 100 | 78 |
| 100 ≤ N0 < 250 | 70 |
| 250 ≤ N0 < 500 | 60 |

명세서 계열 5개 문서 전수 검색에서 **대응 기재 0건**. 근거는 도입 커밋 `d5525e0`(2026-05-04)
메시지에만 있다 (IUCN Criterion D, Frankham 50/500, 단일 멸종사건 취약성).

### 영향이 세 곳에 걸친다

| 영향 대상 | 종 수 | 내용 |
|---|---:|---|
| **① 점수** | **48** (교정 전 47) | floor 를 끄면 점수가 내려가는 종. 전부 큐레이티드. 티어가 갈리는 종 24 (교정 전 23) |
| **② Damuth K** | **25** | 48종 중 체중이 있어 Damuth 계산 대상이 될 수 있는 종. K 를 바꿔도 floor 가 덮어 점수 불변 |
| **③ 챗봇 비교 순위** | **124†** (교정 전 121) | floor 를 끄면 같은 등급·분류군 그룹 안 점수 순위가 바뀌는 종 (비교 블록 대상 289종 중) |

①은 `seed: 42` 로 센 값이고(`docs/population-floor-audit.md` 와 같은 방식), ③은 DB 와 같은
기본 시드로 센 값이다. ③에서 비교 블록 대상 289종 중 floor 에 묶인 종은 **40†** (교정 전 39),
floor 에 묶인 종이 있는 그룹은 **11†** 개다.

교정 후 새로 floor 에 묶인 종은 **마밀라리아 미크로헬리아(EN, N0 499)** 1종이다 — class_name 이
빈값에서 식물(쌍떡잎)로 바뀌어 하한 적용 전 점수가 floor 60 아래(52.2)로 내려갔다.
풀려난 종은 없다(백업 DB 와 대조). 묶인 48종 중 19종이 이번에 class_name 이 교정된 종이다.

### 2026-10-03 결정 — 유지 + 표시 (로드맵 결정 1)

하한 규칙의 조건·값은 그대로 두고, 하한이 점수를 정한 종에는 그 사실을 밝힌다.

| 표시 위치 | 내용 |
|---|---|
| 챗봇 | 컨텍스트에 "개체수 하한 규칙 적용됨: …, 하한 적용 전 점수 47.1점" 줄 (`lib/floor-transparency.ts` → `lib/chat-context.ts`). 시스템 프롬프트가 점수 옆에 이 문구를 쓰라고 지시하고, 모델이 점수 값을 말하면서 빠뜨리면 서버(`finalizeReply`)가 덧붙인다 |
| 계산 근거 페이지 | `/species/<id>/calculation` 요약 상자와 종합 표의 "개체수 하한" · "하한 적용 전 점수" 줄 |
| 종 상세 | 점수 옆 하한 안내 (`floorStatusLine`, 2026-09 부터) |

엔진 5.1.0 에서 하한이 점수를 정한 종은 **40** (CR 31 · EN 7 · VU 1 · LC 1, DB 시드). 하한을 빼면 티어가 바뀌는 종 **21**.
블렌딩(로드맵 결정 6)으로 7종이 하한을 넘어서 47 → 40 이 됐다 (`docs/max-blending-impact-2026-10-03.md` §1).

## 2. Damuth K

### 현상

코드 K = `r < 0 ? max(N0×1.5, N0+100) : max(N0×1.2, N0+50)` — 체중·서식면적 입력 없음.
명세서(PKA-1551 C-1, 발명신고서 §8)는 Damuth 로 자바코뿔소 K ≈ 148, 코드는 126.
`lib/allometry.ts` 의 `damuthK()` 는 `evaluateTippingPoint` 가 호출하지 않는다 (호출처는 테스트뿐).
K 는 PVA 점수와 골든타임(h3) 날짜 산출 두 곳에 들어간다.

### 선행조건 3단계 — 각 단계 없이 진행하면

| 단계 | 현재 상태 | 이 단계 없이 도입하면 |
|---|---|---|
| ① 서식면적 데이터 | `habitat_area_km2` **컬럼 자체가 없음**, 보유 **0종** | `damuthK` 가 전 종에 `null` → **변동 0종**. 도입해도 아무 일도 안 일어난다 |
| ② kg/g 단위 (항목 6) | 상수 91.2 는 kg 기준, 함수는 g 을 받음 | K 가 **1/177.8 로 축소**. 자바코뿔소 K = **0.82** (N0 = 76 보다 작음) |
| ③ floor 재검토 (항목 1) | 미결정 | floor 에 묶인 종은 K 를 바꿔도 **점수 불변**. 자바코뿔소는 K 를 0.82~400 으로 500배 바꿔도 78.0 고정 (가중합 최대 72.16 < floor 78) |

### 2026-10-03 구현 (로드맵 결정 7)

`lib/damuth-k.ts` — `K = d · W^−0.75 · A` (W kg, A km²). 엔진은 체중·서식 면적·**검증된** 상수가 모두 있을 때만 Damuth K 를 쓰고,
하나라도 없으면 기존 식(`max(1.2·N0, N0+50)`, 감소 추세면 `max(1.5·N0, N0+100)`)으로 돌아간다. 쓰지 못한 이유를
`payload.inputs.K_damuth_skip` 에 남긴다 (계산 근거 페이지에 표시).

| 선행조건 | 상태 |
|---|---|
| ① 서식 면적 | `species.habitat_area_km2` 컬럼 추가 (`scripts/migrate-habitat-area.ts`), **값 0종** — 출처 결정 전 |
| ② 단위 (항목 6) | 해결 — kg 기준 상수로 통일 |
| ③ 분류군 상수 | 포유류 91.2 만 출처·단위 확인. 조류 55.0 · 파충류 12.0 · 양서류 200 은 미검증이라 Damuth 를 쓰지 않는다 |

지금 Damuth K 로 계산되는 종 **0** — 점수 변동 0. 서식 면적을 채우는 일은 `docs/iucn-token-checklist-2026-10-03.md` (IUCN AOO·EOO).

## 6. damuthConstant — kg/g 단위 + 17개 분류군 fallback

### 현상 — 단위

`docs/phase2-allometry-constants.md` 는 "W = grams" 라 적고 포유류 d = 91.2 를 싣는다.
91.2 는 **kg 기준 상수**다.

| 계산 | 결과 |
|---|---:|
| 명세서 `91.2 × 2000^(−0.75) × 480` (kg) | 146.4 |
| 코드 `damuthK(2_000_000, "포유류", 480)` (g) | **0.82** |
| Damuth 1981 원식 `10^4.23 × 2e6^(−0.75) × 480` (g) | 153.3 |

`1000^0.75 = 177.8`, `91.2 × 177.8 = 16,218` ↔ 원논문 절편 `10^4.23 = 16,982`.
`__tests__/allometry.test.ts:37` 이 이 짝을 기대값으로 고정하고 있다.

### 현상 — fallback

전용 상수는 4개 (포유류 91.2 / 조류 55.0 / 파충류 12.0 / 양서류 200).
v5 `LIFE_HISTORY` 21개 분류군 중 **17개**가 포유류 91.2 로 fallback 한다 —
어류 3계열·곤충·거미류·갑각류·복족류·이매패류·산호류·식물 4계열·양치식물 2계열·이끼류·지의류.

## 7. EWS — 명세서는 시계열 기반, 코드는 추세 추정

### 현상

명세서의 EWS 는 종별 연도별 개체수 시계열 N(t) 를 입력으로 한다 — 추세 제거 → 이동 창(길이 × 0.5)마다
자기상관(AR1)·분산·왜도·첨도·복귀 속도(1 − AR1) → 각 지표의 Kendall τ → 가중합 → sigmoid.
코드(`lib/tipping-point.ts` `evaluateEws`)는 시계열을 받지 않고, 추세로 정한 성장률 r 하나로
`τ = clamp(−r ÷ 0.06, −1, 1)` 를 추정해 모든 지표에 같은 τ 를 넣는다. DB 의 개체수 시계열은 **0종 · 0시점**이다.

| 항목 | 명세서 | 코드 |
|---|---|---|
| 입력 | 개체수 시계열 N(t) | 추세(IUCN → 한글 칸 → 기본값)로 정한 r |
| τ 가중치 | `0.30·τ(AR1) + 0.25·τ(Var) + 0.20·τ(Skew) + 0.10·τ(Kurt) − 0.10·τ(ReturnRate)` (`scripts/build-verification-package.ts` 명세 텍스트) | 0.5 · 0.3 · 0.2 (세 τ 가 같은 값) |
| sigmoid 계수 | 3.0 (`full_spec` §2.6) · 2 (`build-verification-package.ts` 텍스트) — 명세서 계열끼리 다르다 | 2 |
| 신뢰도 | — | 0.25 고정 (항목 8) |

계산 310종의 EWS 는 추세 입력에 따라 4가지 값만 갖는다:

| EWS | 종 수 | 추세 입력 |
|---:|---:|---|
| 88.08 | 183 | IUCN 감소 |
| 66.08 | 48 | IUCN Unknown + 한글 칸 없음 → 기본값 |
| 50.00 | 47 | IUCN 안정 |
| 11.92 | 32 | IUCN 증가 |

sigmoid 계수 차이는 τ = 0 인 종(안정)에서는 값이 같고 τ ≠ 0 인 종에서는 갈린다 — 예: 바키타(τ = 1)
코드 88.08, 명세서 계수 3.0 으로 95.26.

## 10. Ricker 폭주 — 음의 r_t 에서 N > K 이면 개체수가 발산 (새 항목, 2026-10-03)

### 현상

PVA 는 `N(t+1) = Poisson(N · exp(r_t · (1 − N/K)))`, `r_t = log λ_t` (λ_t 로그정규)다. 그해 r_t 가 음수이고 N 이 K 를 넘으면
지수 `r_t · (1 − N/K)` 가 **양수**가 되어 개체수가 늘어난다 (양의 되먹임). 이것이 반복되면 `exp` 가 Infinity 로 넘치고
Poisson 정규 근사에서 `Infinity − Infinity = NaN` 이 된다.

뿌리는 **밀도 의존 속도에 성장률 자체(추세에서 온 r ≤ 0)를 쓴 것**이다. 영향받는 95종은 전부 평균 r ≤ 0 이다
(83종은 r < 0: −0.06 66종 · −0.02 17종). 평균 r 이 음수이면 표준 확률 Ricker 형 `N · exp(r̄ · (1 − N/K) + ε_t)` 에서도
N > K 일 때 `r̄ · (1 − N/K) > 0` 이라 K 가 위에서 불안정해지고 발산은 그대로 남는다 — 잡음의 부호만 바꿔서는 고쳐지지 않는다.
발산을 없애려면 밀도 의존에 양의 고유 성장률(예: 생활사의 r_max)을 쓰고 추세를 별도 이동 항으로 두거나, 상한을 둬야 한다.

**폭주했다가 0 으로 떨어지는 궤적은 지금도 멸종으로 센다.** 무효 판정은 값이 유한하지 않게 된 궤적만 잡는다. N 이 K 의 수백~수천 배로
불어난 뒤 그해 r_t 가 양수이면 `exp` 가 0 으로 떨어져 N = 0 → 유효한 "멸종" 이 된다. 엔진 5.1.0 에서 N 이 한 번이라도 1000·K 를 넘은
궤적 1,022개(108종) 중 606개는 무효로 빠지고, **396개는 100년 안 멸종으로 세어진다**(85종, 그중 50년 안 53개), 20개는 거대한 값으로
끝까지 살아남아 생존으로 세어진다 (2026-10-03 엔진 사본 계측, 적대적 검토 engine-3).
Damuth K(항목 2)가 N0 보다 작으면 출발부터 N > K 라 폭주가 크게 늘어 — 엔진은 Damuth K 가 max(1.2·N0, N0+50) 보다 작으면 쓰지 않는다
(`K_damuth_skip = below_n0_bound`, 2026-10-03).

| 항목 | 값 (엔진 5.1.0) |
|---|---:|
| 무효 궤적이 생기는 종 | **95** (전부 r ≤ 0) |
| 무효 궤적 | **606** (해당 종 궤적의 0.43%) |
| 그중 멸종 판정에서 `Math.min(1, NaN) = NaN` | 152 (66종) |

로드맵 결정 8 로 **무효 궤적을 확률·분위수·골든타임 집계에서 빼고** 유효 궤적 수를 `payload.layer_scores.pva.n_valid` 에 남긴다.
폭주 자체(위 양의 되먹임)는 고치지 않았다 — 모형식을 바꾸면 무효 궤적이 없는 종의 PVA 도 모두 바뀌기 때문이다.
