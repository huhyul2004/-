## 1. 개체수 floor — 명세서에 추가할지, 코드에서 뺄지

`Math.max` 이므로 점수를 올리기만 한다.

| 조건 | floor |
|---|---:|
| N0 < 50 | 90 |
| 50 ≤ N0 < 100 | 78 |

## 2. Damuth K — 도입할지

### 현상

코드 K 는 `r < 0 ? max(N0×1.5, N0+100) : max(N0×1.2, N0+50)` 이며
체중·서식면적·분류군이 입력에 없다. 명세서(PKA-1551 C-1, 발명신고서 §8)는
Damuth 로 자바코뿔소 K ≈ 148 을 제시하나 코드값은 126 이다.

`lib/allometry.ts` 에 `damuthK()` 가 구현되어 있으나 `evaluateTippingPoint` 가
호출하지 않는다. 호출처는 `__tests__/allometry.test.ts` 뿐이다.

K 는 PVA 레이어뿐 아니라 골든타임(h3) 날짜 산출(`trajectoryToScore`, 649행)에도 들어간다.

### 근거 문서

- `docs/damuth-k-simulation.md` (K 사용처·입력 가용성·시뮬레이션·K 스윕)
- `docs/pka-1551-discrepancies.md` §2 (K 148 대조)

### 선행조건 3단계

| 단계 | 내용 | 현재 상태 |
|---|---|---|
| ① 데이터 | `habitat_area_km2` 컬럼 신설 + 값 확보 | **컬럼 자체가 없음.** 값 보유 **0종**. `habitats` 테이블도 면적을 담지 않음 |
| ② 단위 | `damuthConstant` 의 kg/g 정리 (항목 6) | 미해결. 현재 코드로 켜면 자바코뿔소 K = 0.82 |
| ③ floor | floor 규칙 재검토 (항목 1) | 미결정. floor 가 덮으면 K 를 바꿔도 점수 불변 |

### 선택지와 영향 종 수

| 선택지 | 점수가 바뀌는 종 |
|---|---:|
| A. 지금 도입 | **0** (서식면적 0종 → 전 종이 현재 식으로 fallback) |
| B. ①만 해결 후 도입 | 최대 210 (체중 보유 종) — 실제 수는 확보한 면적 데이터에 달림 |

## 6. `damuthConstant` kg/g 단위 + 17개 분류군 fallback

### 현상 — 단위

`docs/phase2-allometry-constants.md` 는 "모두 W = 성체 체중(grams) 기준" 이라 적고
`d` 표에 포유류 91.2 를 싣는다. 그러나 91.2 는 **kg 기준 상수**다.

| 계산 | 결과 |
|---|---:|
| 명세서 `91.2 × 2000^(−0.75) × 480` (W = kg) | 146.4 |
| 코드 `damuthK(2_000_000, "포유류", 480)` (W = g) | **0.82** |
| Damuth 1981 원식 `10^4.23 × 2e6^(−0.75) × 480` (W = g) | 153.3 |

`1000^0.75 = 177.8`, `91.2 × 177.8 = 16,218` ↔ 원논문 절편 `10^4.23 = 16,982`.

`__tests__/allometry.test.ts:37` 이 이 짝짓기를 기대값으로 고정하고 있다.

### 현상 — fallback

`damuthConstant` 의 분류군 상수는 4개다.

| 분류군 | d | 상태 |
|---|---:|---|
| 포유류 | 91.2 | 전용 |
| 조류 | 55.0 | 전용 |
| 파충류 | 12.0 | 전용 |
| 양서류 | 200 | 전용 |
| **그 외 17개 분류군** | 91.2 | **포유류 fallback** |

v5 `LIFE_HISTORY` 21개 분류군 중 4개만 덮는다. 어류 3계열·곤충·거미류·갑각류·
복족류·이매패류·산호류·식물 4계열·양치식물 2계열·이끼류·지의류가 포유류 값을 쓴다.
