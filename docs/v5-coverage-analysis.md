# v5 커버리지 & 독립변수 분석 (2026-08-01)

v5 = 개체수 데이터 전용 위험 점수. IUCN 등급/Criterion 기반 개체수 추정을 전면 제거.
(브랜치 `v5-population-only`, main 미배포)

## ① 카운트 정리 (자소서·특허 표기 기준)

큐레이션 4,230종:

| 그룹 | 종수 | 성격 |
|---|---|---|
| **실측 계산** | **310** | 개체수 데이터로 실제 산출한 위험 점수 |
| ├ 사이트 수기(mature_individuals) | 13 | 자체 큐레이션 실측 |
| └ IUCN 명시 개체수(iucn_population_size) | 297 | IUCN 평가서에 명시된 개체수(count) |
| **절멸 확정 (EX/EW)** | **270** | 점수 100 = 계산이 아니라 **사실 표시** |
| **데이터 부족** | **3,650** | 실측 개체수 없음 → 점수 없음, IUCN 등급 정보만 제공 |

### 표기 원칙
- ❌ "580종 계산" (과장 — 절멸 사실 + 계산을 섞음)
- ✅ **"310종 개체수 기반 계산 + 270종 절멸 사실 반영"**
- ✅ "나머지 3,650종은 실측 개체수 부재로 점수 미산출(정직한 데이터 부족 표기)"

### 의미 (순환논증 반박)
기존 방식은 등급(CR→200마리 식)으로 개체수를 추정해 4,230종을 다 채웠으나,
그것은 **"우리 점수 = IUCN 등급의 재표현"**이라는 순환이었다. v5는 이 추정을 버리고
**실측 개체수가 있는 310종만** 독립적으로 계산 → 순환 제거. 대신 커버리지는 급감.
검증 3종(바키타 100·자바코뿔소 78·시베리아호랑이 66.5)은 등급 floor가 아니라
실측 개체수·PVA에서 나오므로 v5에서도 값이 유지됨 = 비순환성의 코드 증거.

## ② 독립 변수 검토 (310 계산종에 개체수 외 변수 추가 가능성)

### 순환성 판정 (IUCN 등급 산정에 쓰이는가?)

| 변수 | IUCN 순환 | 결론 | v5 채택 |
|---|---|---|---|
| A. 성체 체중 mass_g | 등급 산정 미사용 | **독립** ✓ | 후보 |
| B. 세대시간 T_gen | Criterion A의 3세대 감소율에 간접 | 애매 | mass 산출식만 (IUCN 서술 T_gen 직접사용 금지) |
| C. 번식속도 r_max | 등급 직접 미사용, Fenchel로 mass서 산출 | **독립(mass 기반)** ✓ | 후보 |
| D. 서식지 면적 habitat_area | Criterion B 근거 | **순환** ✗ | **금지** |
| E. 감소율 | Criterion A 근거 | **순환** ✗ | 금지 |
| F. 유효개체군 Ne | Criterion C 부분 사용, mass 산출은 독립 | 방식별 상이 | 신중 (현재 Ne=N×ne_nc, 개체수 기반이라 OK) |

→ **독립적으로 안전한 추가 변수 = mass_g, 및 그로부터 산출한 r_max(Fenchel).**
habitat_area·감소율은 순환이라 배제.

### ②-2. 알로메트릭 통합 시 점수 변화 — **정량 시뮬레이션 불가 (사유 명시)**

`lib/allometry.ts`(Fenchel r_max·MTE T_gen·Damuth)는 **작성됐으나 미배선**(계산 무영향).
정량적 "점수 변화" 예측을 지금 낼 수 없는 이유:

1. **모델에 소비 슬롯 없음**: 현재 `evaluateTippingPoint`은 r(추세 기반)·N0·ne_nc만
   쓰고 **r_max·generation_time을 소비하지 않음**. 알로메트릭 값을 넣을 자리를
   먼저 설계해야 함(예: PVA 성장률 상한을 r_max로, Ne 계산에 T_gen 반영 등).
2. **MTE T_gen 상수 결함**: b=0.0037은 세대시간을 ~100배 과소산출(바키타 20일).
   T_gen 통합은 상수 재보정 전까지 불가.
3. → **당장 통합 가능한 건 Fenchel r_max(mass 기반, 비순환)뿐**이고, 그것도
   "PVA에 어떻게 반영하는가"라는 설계 결정이 선행돼야 정량 시뮬레이션이 가능.

**정성적 예측(방향만):** r_max를 PVA 성장률 상한으로 도입하면 —
대형 포유류(낮은 r_max)는 회복력 낮음 → 위험↑, 소형종은 위험↓. 109종 한정 효과.

### ②-3. Damuth K / habitat_area — 현재 v5 처리

- **현재 v5의 K(환경수용력) = 개체수 기반 휴리스틱** (`K = max(N0×1.5, …)`, tipping-point.ts:556).
  Damuth·habitat_area **미사용**.
- Damuth K는 `density(mass) × habitat_area`인데 **habitat_area가 Criterion B 근거라
  순환**. → v5에서 Damuth K **도입 금지**. 현재의 N0 기반 K 유지가 비순환 관점에서 안전.

## 결론 / 통합 여부 판단 재료
- **비순환 추가 변수 후보: mass_g + Fenchel r_max (109종 한정)**.
- 통합하려면 (a) PVA에 r_max 진입 방식 설계, (b) MTE 상수 재보정(T_gen 쓸 경우) 필요.
- habitat_area·감소율·IUCN 서술 T_gen 직접사용은 순환이라 배제.
- 통합해도 **109종에만 영향**(커버리지 확장 아님). 커버리지(310)를 늘리려면
  체중이 아니라 **실측 개체수 데이터 확보**가 관건.
