# IUCN 등급 vs 체중 통계 분석 — 포유류 148종 (2026-08-02)

## 가설
**H1: IUCN 등급이 높을수록(더 위협받을수록) 종의 성체 체중이 클 것이다.**
(대형종일수록 멸종 위험이 높다는 보전생물학 통념)
- 독립변수 X: log₁₀(성체 체중 g)
- 종속변수 Y: IUCN RLI 가중치 (LC=0·NT=1·VU=2·EN=3·CR=4)

## 판정: **가설 기각 — 상관 없음 (H1 REJECTED, no relationship)**
- Pearson r = −0.05, p = 0.54 → **통계적으로 유의하지 않음.**
- 95% CI가 **0을 포함** → "상관 없음"을 배제하지 못함.
- Spearman ρ = −0.11, p = 0.17 → 순위상관도 유의하지 않음.
- R² = 0.3% → 체중은 등급 분산을 사실상 설명하지 못함.
- **결론: 포유류 내부에서는 체중과 IUCN 등급 사이에 통계적으로 검출 가능한 관계가 없다.**

## 조류를 뺐을 때 상관 변화 (해석)
- 전체 표본에서는 "**통념과 반대로 등급↑일수록 체중↓**"(r=−0.24, p<0.001)의 **유의한 음의 상관**이 나왔다.
- 그러나 **조류 56종을 제외하자 상관이 사실상 소멸**했다 (r=−0.24 → **−0.05**, 79%↓; p<0.001 → **0.54**).
- 즉 전체 표본의 음의 상관은 **거의 전부 조류가 만든 것**이었다:
  - 조류는 **소형이면서 CR/EN/VU**(정밀 개체수 조사된 위협 조류)에 집중.
  - 포유류는 **대형 LC**(판다·곰 등)와 다양한 등급에 분산.
  - 두 분류군을 합치면 "작은 체중 = 높은 등급"이라는 기울기가 인위적으로 형성 → **혼재변수(분류군)에 의한 겉보기 상관.**
- 산점도로도 확인: 포유류 단독 회귀선은 **거의 수평**(r=−0.051).

## 한계 (정직한 서술)
1. **편의추출**: "실측 개체수 있는 종"만 표본 → 잘 연구된 종에 치우침(무작위 아님).
2. **위협종 소수**: 포유류 위협종 49종(VU 7·EN 8·CR 34)으로 검정력 제한.
3. **단일 분류군**: 포유류에 한정 → 전 분류군 일반화 불가.
4. 단, 분류군 혼재는 제거되어 v2보다 **교란(confounding)은 적음**.
